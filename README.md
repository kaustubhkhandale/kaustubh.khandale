# Kaustubh Khandale Portfolio

This is a Next.js portfolio site built with the App Router.

## Run locally

**Prerequisite:** Node.js 18.18 or newer.

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000).

## Production checks

Run `npm run lint` for type checking and `npm run build` to verify the production build.
